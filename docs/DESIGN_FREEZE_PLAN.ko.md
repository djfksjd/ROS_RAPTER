# 형상 동결 계획: 반복 루프 끊기 (2026-11-03 합의안)

사용자 요청은 "강화학습을 많이 했는데 쓸모없는 시간이 되고 계속 다시 돌아간다. 합의안 고도화 계획을 쓰고 진행하라"였다.
같은 자료(`docs/STAGED_PLAN.ko.md`, 증거 186–192)를 Codex(gpt-6-astra)와 Claude Fable이 각각 따로 검토했다. 이 문서는 두 검토의 합의안이다. 진행 기록은 맨 아래 표에 계속 적는다.

## 1. 진단 (두 검토 합의)

| 원인 | 근거 |
|---|---|
| **형상을 확정하기 전에 비싼 강화학습을 돌렸다** | 0단계(증거 186–187)는 모터·감속·질량만 통일했다. 다리 비율(0.22 : 0.38 : 0.32 m, 합 0.92 m)은 R-02(10.5 kg, 등급 모터) 해석식에서 고른 27개 후보 중 하나다. 허벅지와 발등뼈는 그리드 끝값이다. 15.1 kg·RS04·4절 무릎인 R-03에서는 다시 계산하지 않았다. 꼬리(뿌리가 엉덩이 뒤 20 cm, 무게중심 97 cm)는 관성비 하나로 정했다 |
| **강화학습을 "가능한가" 판정기로 썼다** | 0이 나오면 탐색 문제인지 기구 문제인지 가를 수 없다. 무릎 2.0 rad 제한(행동 배율)과 배 높이 24.5 cm는 비RL 계산으로 1시간이면 알 수 있었다. 실제로는 강화학습 수십 시간 뒤에 알았다(증거 191–192) |

| **B/A 판정 근거가 낙관적이다** (Fable 추가, 코드로 확인) | 설계 보폭 모델(`modeling/spec_40kmh.py` 16행)은 지지 중 지면 반력이 고관절을 지난다고 보고 고관절 토크를 0으로 둔다. 정책이 쓴 "고관절 2.5배"는 정책의 비효율이 아니라 설계 모델의 공백일 수 있다. 몸통 pitch 유지와 가감속은 모두 고관절 토크다. 이것을 3단계까지 미루면 몇 주를 쓴 뒤 같은 결론으로 돌아온다 |
| **실험마다 사전 중단 기준·예산이 없었다** | 증거 189–192에는 "N 스텝에서 X 미달이면 중단"이라는 선언이 없다. 기준이 있던 1a는 통과했다 |
| **실험 조건이 도중에 바뀌었다** (Codex 추가) | 바닥 강성, 모터 곡선, 보상 항이 실험 도중에 바뀌어 이전 수치와 직접 비교할 수 없게 됐다 |

**버려지지 않은 것:** 학습 하네스(`train_run.py`, `stage_gates.py`, 실물 모터 조건 rev3), 계산 도구(`stage0_b_study.py`, `knee_fold_study.py`, `fold_geom.py`, `getup_search.py`), 1a 설정 노하우, rev2 보상·지형 커리큘럼은 모두 그대로 쓴다. 형상을 바꾸면 잃는 것은 정책 가중치뿐이다. 설정을 아는 지금 1a를 다시 통과하는 데 드는 비용은 약 하루(6–11M 스텝)다.

## 2. 원칙

1. **강화학습 전에 비RL 계산으로 상한·하한을 잡는다.** 해석식, 궤적·제어기 매개변수 탐색, 키프레임 CEM을 쓴다. 최종 재생은 `RunEnv.step()`과 같은 물리 경로(래칫·지연·필터·발열·T-N 곡선)로 한다.
2. **탐색이 실패하면 "미해결"이다. "불가능"으로 선언하지 않는다.** 정해진 예산 안에 경로를 못 찾았다는 결과는 사용자 결정(범위 축소·기구 변경)의 근거로 쓴다.
3. **형상은 사용자 결정 1회로 동결한다.** 동결 뒤 형상을 다시 여는 조건은 재현되는 모델 오류이거나 필수 운동의 구체적 제약 위반뿐이다. 강화학습 정체만으로는 다시 열지 않는다.
4. **모든 학습·탐색은 시작 전에 예산과 중단·채택 기준을 증거 README에 먼저 적는다.**
   - 강화학습 한 번의 상한은 8M 스텝(약 4–5시간)이고, 연장은 1회만 한다.
   - 1M 스텝마다 고정 개발 시드로 평가한다.
   - 2M 스텝 동안 개선이 없거나 4M에서 성공률이 0이면 중단하고 비RL로 원인을 가른다.
   - 학습 보상이 오르는 것만으로는 연장하지 않는다.

## 5. 두 검토의 차이와 처리

| 항목 | Codex | Fable | 합의 |
|---|---|---|---|
| 첫 작업 | 계약 → 형상 선별 → 기상 탐색 | 달리기 가능성 → 기상 탐색 → 다리 비율 | 계약(짧게) → 형상 해석 선별 → 달리기 → 기상. 달리기가 B/A와 형상을 함께 정하므로 기상보다 앞에 둠 |
| 탐색 실패의 의미 | 미해결, 불가능 선언 금지 | 0이면 "현 기구로 불가 확정" | 미해결로 기록. 사용자 결정의 근거로는 사용 |
| 이전 정책 | 비교 기준·시연 자료, 가중치 전이는 후보 초기화로만 | 설정 자산, 전이 1M 시험 | 둘 다. 전이는 1M 시험으로 가능 여부만 확인 |
