# Codex gpt-6.1-sol review: equal-condition structure comparison (2026-10-01)

1. **현재 안은 유용한 비교지만, 그대로 구조를 확정하기에는 편향이 있습니다.**
   - E1/E2의 실제 질량 차이는 정당합니다. 다만 결과는 **완성 설계 비교**이며, 축 수만의 효과를 분리하지는 못합니다.
   - 모두 처음부터 학습하는 것은 공정합니다. 그러나 arch8e의 최종 보상 계수·스프링·감속비는 이미 8축에 맞춰 탐색됐습니다. 동일 설정 비교 후, 각 구조에 **동일한 추가 튜닝 예산**을 줘야 합니다. 기존 arch8e는 참고 기준으로만 두십시오.
   - 12축의 대퇴 장착은 모터 질량을 대퇴 관성에 반영해야 합니다. 케이블·풀리·지지대 질량, 마찰·탄성·백래시·전달 반력 없이 구현하면 12축에 유리합니다.
   - 같은 무릎 스프링도 하중·자세가 다른 구조에 동일하게 적합하지 않습니다. **공통 스프링 시험 + 동일 예산의 구조별 튜닝 시험**을 구분하십시오. 12축에만 있는 발목 클러치의 효과도 별도 제거 시험으로 확인해야 합니다.

2. **비교 전에 발열·질량 구현을 먼저 고쳐 검증해야 합니다.**
   - 확인한 `sim/rl/run_env.py`는 무릎 발열 환산에 **평균 전달비 1.4**를 사용합니다. 실제 전달비가 1.0–2.05라면 매 물리 스텝의 전달비로 모터 토크·속도를 계산해야 합니다.
   - 현재 모터 곡선·발열 처리는 `arch8` 조건에 묶여 있습니다. E2에도 같은 계산이 적용되는지 계약 시험이 필요합니다.
   - 총질량만 맞추는 균일 스케일링으로는 부족합니다. 부품별 질량·CoM·관성, 구동기 회전자 반사 관성을 확인하십시오.
   - 이 발열값은 **가정된 연속토크 기준의 부하 지표**입니다. `heat≤1`만으로 실제 모터 온도나 하드웨어 지속 운전을 입증하지 못합니다.

3. **E3는 몸통 기준 고관절 장착점을 뒤로 옮기는 모델이어야 합니다.**
   - 몸통 탑재물은 실제 장착 위치에 유지하고, 골반·고관절 구동기·다리 및 다리에 부착된 모터는 장착 관계에 따라 이동시킵니다. 보강재·전달계 변경도 질량에 포함합니다.
   - 꼬리 뿌리는 몸통 후단에 유지합니다. 고관절 이동을 따라 꼬리까지 자동 이동시키면 제시된 R-03와 다른 실험입니다.
   - 이동 후 전신 CoM과 관성을 다시 계산하고, 연동 발목 제약·관절 한도·충돌·스프링 예압을 만족하는 초기 자세를 역기구학으로 구하십시오. 대퇴 전경 약 20°는 초기 추정이며 검증 결과가 아닙니다.
   - 정지 초기 자세에서는 CoM 투영이 지지영역 안에 있도록 합니다. 달리기 중 발을 항상 CoM 바로 아래로 강제해서는 안 됩니다.
   - **0.2 m를 정답으로 고정하지 마십시오.** 0/0.1/0.2/0.3 m의 기구학·정적 지지를 먼저 검사하고, 가능한 후보만 동적 비교하십시오. E3만으로 12축에서의 R-03 효과까지 판단할 수는 없습니다.

4. **2 seeds는 선별용입니다. 고정된 최소 steps로 신뢰성을 보장할 수 없습니다.**
   - 실무 권고는 후보당 **독립 학습 3 seeds로 예비 비교**, 접전이면 최종 후보를 **5 seeds 이상**으로 확대하는 것입니다. 이것도 통계적 보장 숫자는 아닙니다. SB3도 여러 실행과 별도 평가 환경을 권고합니다. [공식 평가 지침](https://stable-baselines3.readthedocs.io/en/master/guide/rl_tips.html)
   - 30M은 공통 예산으로 쓸 수 있지만, 학습곡선이 계속 상승하면 구조 한계가 아니라 학습 부족일 수 있습니다. seed별 성능과 커리큘럼 도달 단계도 보고하십시오.
   - 먼저 실제 설정으로 짧게 처리량을 측정하십시오. 3설계×2 seeds×30M은 **180M transitions**입니다. 3시간이면 학습 업데이트·평가를 포함해 약 **16,700 transitions/s**가 필요합니다. 10코어만으로 가능하다고 단정할 수 없습니다.
   - 시간이 부족하면 짧은 공통 예산으로 선별하고, 남은 후보에 동일하게 추가 예산을 배정하십시오. 결론은 잠정 판정으로 남깁니다.

5. **지속속도 판정과 구조 동결 전 측정을 보강하십시오.**
   - 11.1 m/s 명령의 90%는 **9.99 m/s**입니다. 현재 기준 통과와 **40 km/h 실제 도달**을 별도로 보고해야 합니다.
   - 준비운전·열 초기값·명령 상승 절차·정상상태 평가 구간을 고정하고, 후반 구간의 속도·모터별 발열 최대값·발열 추세를 기록하십시오. 경계 속도는 0.25–0.5 m/s 간격으로 좁히고 여러 초기조건·보행 위상에서 반복합니다.
   - 교란은 동일한 절대 임펄스와, 관성 차이를 고려한 동일 초기 각속도 변화 시험을 함께 수행하십시오. 회전은 실제 전진속도·회전반경·요 추종·감속을 함께 측정합니다.
   - 동결 전에는 모터 토크–속도 궤적·포화율, 버스 전력·제동 에너지, 스프링/클러치 에너지 수지, 링크·케이블 최대하중, 접촉력·미끄럼·발끝 여유, 정지·감속·STOP을 확인해야 합니다.
   - **현재 제시된 근거로 8축/12축 우열이나 R-03 성공은 확정할 수 없습니다.** 다음 한 단계는 세 모델의 구동·발열·질량 계약을 맞추고 학습 처리량을 측정하는 것입니다.
