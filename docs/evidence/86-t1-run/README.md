# 86 — T1 달리기 환경과 첫 학습 (2026-09-30)

**첫 행(구동기·제약):** T1 가상 구동기 — R-02 형상, 질량 균일 축소 5 kg(발가락 스프링은 R-02 값 유지), 스프링 (c)
(엉덩이 130 N·m/rad 단방향 q0 0.041, 무릎 40 양방향 q0 1.395, 발목 57 단방향 q0 −1.215), 구동기 엉덩이 35 N·m/27 rad/s/350 W,
무릎 28/27/225, 발목 22/27/90, 꼬리 36/12/400, 1 ms마다 토크·속도·전력 클램프, 몸통 속도 관측(상태 추정기 가정), 평지.
현재 로봇 구동기의 결과가 아닙니다. 사양서: [docs/design/40kmh-spec.md §9](../../design/40kmh-spec.md).

## 1. 구현 중 실제 확인한 것

| 항목 | 측정 | 결과 |
|---|---|---|
| 단방향 스프링 | 고정 tendon dead-band `springlength` | 엉덩이 q −0.5 → 0, q 0.2 → −20.7 N·m; 발목 q −1.0 → 0, q −1.5 → +16.3 N·m (수식과 일치) |
| 전력 클램프 | 엉덩이 20 rad/s | 힘 범위 ±17.5 N·m(=350/20); 30 rad/s → 구동 방향 0 |
| 사후 전력 초과 | 무작위 행동 60스텝 | 720 표본 중 3개(충격 스텝), 최대 1.7배 → 1 ms 클램프 지연 |
| 정지 기립, 웅크림 자세 | 영 행동 유지 | 발목 스프링 예압 37 N·m > 모터 → 1 s 안에 전도 |
| 정지 기립, 발 평평 자세 스캔 | 무릎 1.0~1.7, 엉덩이 −1.0~0.2 | 발목 8 N·m: 서는 자세 없음. 12~22 N·m: 마진 자세만. 발가락 스프링 축소 시 W·h 미만으로 3 s 전방 전도 |
| 기본 자세 −0.375/1.50/−1.652 | 영 행동 유지 4 seed | 1.9~2.9 s 뒤 전도(앞·뒤 경계). 균형은 정책의 몫 |
| 처리량 | 환경 8개 PPO | 약 1,900~2,100 스텝/s |

발목 스프링 정지각을 깊게 옮기면(계산기 재실행) 달리기 발목 요구가 급증합니다: q0 −1.215 → 5.8 N·m/68 W, −1.30 → 11.5/159, −1.45 → 26/302 (5 kg).
그래서 정지각은 유지하고 T1 발목 토크만 A급 22 N·m로 두었습니다. 실기 해법은 클러치(BirdBot)이며 미계산입니다.

- **최고 속도(T1 가상 구동기, 평지, 교란 없음): 꼬리 활성 7.3 m/s(26 km/h) 10 s 무전도, 꼬리 고정 6.0 m/s.** 8 m/s 명령에서 꼬리를 고정하면 3/3 전도.
  11.1 m/s(40 km/h)는 두 경우 모두 전도 — 학습 커리큘럼이 5.3 m/s에서 멈췄으므로 미학습 구간입니다.
- 정지 명령에서 서지 못하고 제자리에서 4 Hz로 뜁니다(이동 비용 무의미). 저속에서 진행 방향이 0.2~0.4 rad/s로 돌아갑니다(요 추종 보상 +1이 약함).
- 꼬리-다리 요 각운동량 상관 −0.63~−0.86: 꼬리가 다리의 요 각운동량을 반대 위상으로 상쇄합니다(Bishop 2021의 형태). 꼬리 관절 속도 RMS는 속도에 따라 1.0 → 2.3 rad/s.
- 보폭 3.9~4.6 Hz, GRF 2.2~2.9 BW, 비행 비율 0.54~0.64. 사양서 SLIP 설계점(11.1 m/s, 3.12 Hz, 3.2 BW)과 직접 비교는 속도가 달라 불가.
  7.3 m/s에서 양의 기계 일률 340 W(두 다리 합), 사양서의 5 kg (c) 평균 103 W(11.1 m/s 환산)보다 큼 → 정책이 비효율적.

## 4. 미검증·한계·다음 한 단계

- 모든 수치는 T1 가상 구동기(위 첫 행)·평지·MuJoCo 결과이며 현재 로봇이나 실기 성능이 아닙니다. 40 km/h는 달성하지 못했습니다(최고 7.3 m/s).
- 미검증: 몸통 속도 관측 없는 정책, 지형, 8 kg 사양 재평가, (b) 아킬레스만 비교, 꼬리 없이 학습한 정책과의 비교, 착지각·후퇴 각속도 규칙.
- 결함: 정지 명령에서 제자리 뜀, 저속 요 드리프트, 커리큘럼 5.3 m/s 정체(확률적 넘어짐 ~30 %), 임펄스 회복 시간 기준.
- 다음 한 단계: v2 — 요 추종 가중치 상향·정지 명령 비율 확대·에피소드 15 s로 재학습(`--init` 이어서), 꼬리 고정으로 학습한 대조 정책, 임펄스 회복 기준 수정.
  그 뒤 8 kg + (c) 재평가와 (b) 비교(사양서 §9).
