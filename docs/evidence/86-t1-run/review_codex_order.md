4. **AI/VLM까지의 권고 순서 — 7단계입니다.**

   | 순서 | 작업 | 한 줄 산출물 |
   |---|---|---|
   | 1 | 기존 v8c·couple 결과를 같은 조건으로 비교 | 속도·교대성·접힘·회전·교란·하중 비교표 |
   | 2 | 사용자 목표 속도와 축·연동·클러치·R-03 여부 결정 | 전체 질량·CoM·토크–속도·열 예산을 포함한 설계 동결표 |
   | 3 | 선택 기구를 설계표와 엔진별 모델에 반영 | 재생성 가능한 모델 variant 및 계약 검증 결과 |
   | 4 | GLB 재생성·관절 범위·간섭·표시 확인 | 채택 모델과 일치하는 외형 패키지 |
   | 5 | 기립·저속 보행·주행·회전·정지·교란과 전환 검증 | 통과 동작·속도 범위·실패 조건을 명시한 카탈로그 |
   | 6 | 실제 정책 GLB 영상과 ROS 명령·STOP 경로 검증 | README 증거와 STOP 우선·통신 상실 대응 기록 |
   | 7 | 로컬 VLM 비교와 Laya 행동 선택 연결 | 동일 영상 평가셋의 정확도·지연·메모리·오판 및 제한 시연 결과 |

   RoboBrain 2.0-3B·Moondream·SmolVLM2는 **MLX 실행 가능성부터 확인**하고, 검증된 행동만 Laya에 노출하십시오. VLM 출력은 허용 행동 선택에 사용하며 모터 명령을 직접 생성하지 않습니다. 현재의 위치 유지 STOP은 고속 주행의 안전 정지를 보장하지 않으므로 6단계에서 별도 검증해야 합니다.
