156의 원8축/구동곡선/초기조건/.6초 observer reset/1.6초 연속cap.995를 유지했다. 초기 q관측으로 모터별 target=q−spring_torque/kp를 계산하는 pure NumPy BrakingApproach를 추가했다. 원46관측 중 관절위치12개와 고정 기구매개변수만 사용하며 환경/수동관절 실제값을 직접 읽지 않는다. q가 기준각에서 .2초동안 평형 action으로 이동한다. 이후 .6초까지 평형 목표, 그뒤 기존관측 추정기다. 기본환경/정책/기구는 수정하지 않았다.
