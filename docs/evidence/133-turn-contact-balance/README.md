좌회전에서는 횡방향 CoM 일의 크기가 비슷해도 전진방향 양의 일이 더 작았다. 왼쪽 다리 하중 집중과 고관절 roll 제한 접근(13.2%)도 기록됐으나, 한 초기상태의 상관관계이므로 원인을 입증하지 않는다. 기본 직진을 같은 위상에서 시작해 양방향 회전을 시켰으므로 좌우가 서로 완전히 반사된 물리 초기상태라고 간주할 수 없다.

세계좌표 운동량 수지 잔차 크기는 0.0551/0.0231 Ns, 전신 CoM 수평 에너지 수지 오차는 0.1311/0.0349 J다. 124의 <0.1 J 기준을 좌회전은 넘으므로 더 정밀한 에너지 차이를 확정하지 않는다. 위 일은 전신 CoM 병진운동에 대한 일이며, 접촉점 마찰 소산·모터 전기에너지·전체 회전/스프링 에너지 수지가 아니다. 몸통 전진속도와 전신 CoM 속도도 서로 다른 측정량이다.

부척골 접촉도 기록했다. run_env가 부척골을 발 접촉 집합에 포함하므로 현재 모델에서 새롭게 종료 위반으로 분류하지 않는다. 제작품의 허용 접촉 여부는 별도 미검증이다. 기준선과 실패를 보존하고 운영 모델에 채택하지 않았다. 다음은 회전 시작 시점의 다리 위상·접촉 상태를 바꾼 제한된 진단으로 하중 비대칭과 시작 위상 의존을 분리한다. 전체 goal active.
