# 153 — 기존 관측 기반 기립 추정기

기존 RunEnv의 46개 관측 중 41개(gyro·중력 방향·몸통 속도·12관절 위치/속도·이전8행동)를 사용하는 국소 상태 추정기를 만들었다. 영점 명령3개와 보행 위상2개는 제외한다. 수동 발가락 실제 상태는 제어기에 전달하지 않으며, 실제 상태와 추정치의 차이는 결정 이후 감사 로그에만 기록했다. 관측기는 영점 상태로 시작하며 참 초기 상태를 주입하지 않는다. 오프라인 모델 식별에는 시뮬레이터 전체 상태를 사용했다.

원8축기구·148의 평형·151의 제어 이득·152의 연속 전류 상한 .995를 유지했다. 기존 개발 seed85001–85020의 평형 근처 초기조건(관절 표준편차 .001rad, 초기 vx0–.02m/s)에서 60초 무전도·위치/기울기/비행·마지막40초 가상부하 **20/20 통과**. 상세 최댓값은 summary.json에 저장했다. 새 독립 검증 세트나 원래 시작 자세의 성공으로 해석하지 않는다.

원기준 reset seed83001–83004에서는 **0/4**, .82/.78/.82/.64초에 전도했다. 짧은 실패 구간의 부하 평균은 정상상태 40초 측정이 아니다. 전체 catalogue_pass=false, 기준선 미교체·goal active다. 원시작에서 평형에 접근하는 경로와 가속·감속·STOP 연결이 남아 있다.

추정기 설계의 W=1e-7 I, V=1e-6 I는 측정 잡음에서 식별한 값이 아닌 가정이다. C는 오프라인 fresh 상태로 유한차분했으나 런타임은 실제 반환 관측을 사용했다(일부 변환 값의 물리 한 스텝 지연 포함). 불안정 모드의 수치 관측 가능성과 추정 오차 행렬 반경 약 .9261을 확인했다. 국소 수치 결과이며 전역 안정성 증명은 아니다.

몸통 속도 관측 자체는 시뮬레이터에서 제공된다. 따라서 수동 관절 ground truth를 제거했다고 실물 센서 경로까지 검증한 것은 아니다. 센서 잡음·누락·지연·미끄럼·지형·추가 하중은 미검증이다. 제어기에는 선택형 물리 행동 경계 인자가 있지만 본 실험 설계는 기존 정규화 ±1 경계이며, Env의 실제 관절 목표 제한은 그대로 적용한다. 밖에서 강하게 포화될 때 추정기 입력과 실제 목표의 차이는 별도 검증 대상이다.

순수 NumPy 추정기 입력 검증·외부 설계 변경 격리·reset·제한 행동·상태 불변 실패 처리 포함 집중25검사 통과. 전체146중69통과77환경 의존 생략. 재현은 저장소 루트에서 near20.py/original-start4.py를 사용하며 실행 결과 경로는 기본적으로 새 파일 생성 모드다. 기존 원값을 덮어쓰지 않는다.
