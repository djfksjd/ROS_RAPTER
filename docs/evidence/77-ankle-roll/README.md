# 77 — 발목 roll 추가: 12 능동축 (2026-09-29, 사용자 결정)

사용자 결정으로 다리마다 발목 roll 1축을 추가했습니다(능동축 10 → 12). 기존 10축 실험을 재현할 수 있도록
Xacro 인자 `ankle_roll:=true`(digitigrade 다리 전용, 기본값 false)로 켭니다.

## 구조

- 발목 pitch 관절이 발허리뼈 링크(`<side>_metatarsus_link`)를 움직이고, 발허리뼈 아래 끝(패드 바로 위)의
  `<side>_ankle_roll_joint`(x축, ±0.5rad, 60Nm, 2.5rad/s)가 발 패드와 수동 발가락(`<side>_foot_link`)을 굴립니다.
  지면 가까이에서 굴러 옆 경사에 발을 맞출 때 지렛대가 짧습니다.
- 발 질량은 발허리뼈와 패드에 반씩 나눴습니다. 총질량 17.3kg, 무게중심, 패드 높이는 10축 모델과 같습니다(테스트로 확인).
- `controllers_ankle_roll.yaml`에 12개 관절이 있습니다. 10축 URDF와 MJCF는 수치상 바뀌지 않았습니다(재생성해 비교).
- 발 패드는 아직 평평한 상자입니다. 발바닥 형상은 한 번에 한 변수 원칙에 따라 다음 단계에서 바꿉니다.
