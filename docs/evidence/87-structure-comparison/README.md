**정정·판정:** 기본 골반 후보의 선별 지속 속도 5.189 m/s는 30개 출발 전체 통과로
재확인되지 않았다. 6 m/s 명령에서 한 출발의 무릎 부하가 기준을 0.003524 넘었다.
더 낮은 5 m/s 명령은 최초 3개 출발만 시험했으며, 해당 점의 30개 재확인은 하지 않았다.
후방 골반 후보는 7 m/s 명령에서 세 선별 출발과 30개 추가 출발 모두 통과,
보수적인 실제 지속 속도 **6.166858 m/s (약 22.20 km/h)**를 확인했다.
이는 7 m/s 명령의 88.1%로 카탈로그의 속도 오차 10% 기준에는 미달이다.
발열 지표는 실제 모터 온도·연속 운전 인증이 아니며, 나머지 지형·감속·정지는 미검증이다.
