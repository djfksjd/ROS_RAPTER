154의 원시작을 유지하고 원8축기구/후방골반/모터 곡선/정차 cap.995에서 접근 궤적을 최적화했다. 첫 .6초의4개 시점에 공통 hip roll·좌우 spread·공통 hip pitch·공통 knee pitch·tail pitch를 배치한20개 시간 궤적 변수를 사용한다. 이는 모터 축을 추가한 것이 아니며 출력은8개다. tail yaw는0, 실제 관절 목표 범위를 적용한다. qpos teleport/초기 vx 제거/외부 힘 추가는 하지 않았다.

식별·목적함수에는 실제 시뮬레이터 상태를 쓰는 오프라인 계획이다. 학습 조건은 기존 개발 seed83001 한 개이고83002–83004도 이미 개발에 사용한 조건이다. 최종 독립 검증으로 보고하지 않는다. 목표는 원래60초/위치·기울기·비행·가상부하 기준이며 최적화 목적함수 감소를 성공으로 대체하지 않는다.

## 수치 계산과 실제 재생

상대 수치 미분은 영점 입력에서 간격이 기계 정밀도 수준으로 작아지는 문제를 발견했다. 원94회 결과를 보존하고 절대 중심차분 epsilon .002로 재계산했다. 실제 물리 행동 경계도 명시적으로 적용했다. 절대 미분377회 검색의 초기 비용65.2214, final20.5791, 관측된 best20.4883이었다. best는 optimizer의 final과 다른 유한차분 탐색점이므로 둘 모두 별도 재생했다.

## 전환 뒤 안정성을 포함한 두 번째 목적함수
