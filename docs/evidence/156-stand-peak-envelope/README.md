## 초기 스프링 힘의 제동 목표

기존 접근은 시작부터 무릎을 펴도록 요구해 스프링의 펴는 힘과 같은 방향으로 작용한다. 초기 q/passive force로 target=q−passive/kp를 계산해 첫 knot의 제동 목표로 사용하고, 뒤3개 knot는 기존 평형 목표를 유지했다. 요청 토크는 원 envelope로 제한되며 모터가 스프링 토크를 모두 상쇄한다는 뜻은 아니다. 초기 knot는 개발seed83001에서 계산하고 다른 시작에도 고정 재생했다.

원 peak envelope를 사용한1.6초 계획/.6초 이후 full-state LQR 목적함수를 Powell로259회 평가했다. initial4901.2382, 관측best569.2186, final10150.6182였다. optimizer status0/성공 메시지와 달리 final비용은 initial보다 높았다. 물리성능/실행가능성 인증으로 쓰지 않는다. 초기 두 비용은 정확히 같다.

| 재생 후보 | 개발 성공 |
|---|---:|
| 초기 제동 궤적 + 전환 때 observer reset |1/4|
| 초기 제동 궤적 + full-state LQR |0/4|
| Powell best + observer reset |0/4|
| Powell best + full-state LQR |0/4|

Powell이 개선한 목적함수 후보가 실제 기립을 개선한 것은 아니다. 성공은 최적화 전의 분석적 제동 초기값에서 나왔다. 총개발40회 중1회 통과다. 처음 집계에서16재생을 모두 실패라고 잘못 말한 것을 원값 확인 후 정정했다. 성공 행을 누락한 요약 대신 모든 raw행을 기준으로 집계한다.
