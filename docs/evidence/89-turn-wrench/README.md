# 회전 접촉 모멘트 계측 — 2026-10-09

기준선 `scr_a8_h2`와 보상 변경 `turn_pilot_yaw16_20261009`를 비교했다.
4 m/s, yaw명령 −1/0/+1 rad/s를 4–10초에 적용, 총12초, 출발9001/9002, 12회.
**회전 목표는 여전히 미달이며 기준선을 교체하지 않았다.** T1 가상 구동기 시험이다.

## 계측의 검증과 실패 보존

`mj_contactForce`는 접촉 좌표의 힘:토크를 반환하므로 세계 좌표로 회전한 뒤
전신 무게중심 기준의 `r × F`와 직접 접촉 토크를 더했다. 로봇 내부 접촉은 제외한다.
[MuJoCo 공식 API](https://mujoco.readthedocs.io/en/stable/APIreference/APIfunctions.html#mj-contactforce).
2 kg 상자에 외력 `[5,2,0] N`과 yaw토크0.2 N·m를 가했을 때 접촉 반력은
`[-5,-2,19.62] N`, 접촉 모멘트는 `[0,0,-0.2] N·m`와0.01 이내로 일치했다.
위아래 두 상자 시험은 접촉의 반대 참가자에서 부호를 뒤집는 것도 검증한다.

첫 계측은 위치 계산을 원본 데이터에서 갱신해 기존 관측 시점과 궤적을 바꿨다.
12초 끝 위치 최대차1.474760, 속도차0.441718로 **계측 실패** 처리했다.
이후 상태 복사본에서만 운동량을 계산했다. 처음 수정 시 모델을 reset 전에 생성해
빈 결과 파일과 예외가 발생했고, reset 뒤 복사본을 생성하도록 고쳤다. 실패 파일은 runs에 보존한다.
수정 후 동일 조건의 계측/비계측 한 쌍에서 모든 제어 표본과 최종 qpos/qvel의 최대차가 **정확히0**이었다.
`noninterference.json`에 비교 파일을 기록했다. 원본 환경·정책은 수정하지 않았다.

## 실제 계측 결과

1 ms마다 접촉 모멘트를 적분하고 전신 각운동량 변화와 비교했다.
12회 전도0, 회전 구간의 최대 운동량 수지 잔차는0.004060 N·m·s였다.
이 잔차를0으로 보고하지 않으며 수치 적분·접촉 계산 시점의 한계가 남아 있다.

| 정책 | 명령 | 마지막2초 실제 yaw, 출발2개 | 접촉 모멘트 절대 최대 범위 |
|---|---:|---|---|
| 기준선 | −1 | −0.134 / −0.189 rad/s | 8.289–8.768 N·m |
| 기준선 | 0 | −0.044 / −0.100 | 6.103–6.516 |
| 기준선 | +1 | +0.025 / −0.010 | 5.588–5.892 |
| yaw16 | −1 | −0.219 / −0.274 | 8.404–9.323 |
| yaw16 | 0 | −0.075 / −0.112 | 4.917–5.333 |
| yaw16 | +1 | +0.078 / +0.046 | 4.826–5.019 |

접지에서 양·음 방향 모멘트가 모두 생기고 명령에 따른 운동량 변화도 측정된다.
따라서 검사한 정책에서 ‘명령이 관측에서 사라짐’ 또는 ‘지면 yaw모멘트가 항상0’이라는 설명은 지지되지 않는다.
양·음 토크가 상쇄된다는 사실만으로 실패 원인을 확정하지 않는다. 일정 각속도를 유지할 때
순 외력 모멘트가 작을 수도 있으며, 이 계측은 최대로 가능한 기구 성능의 시험이 아니다.
기존 동일 상태 명령 감도 시험에서 고관절 roll 출력의 포화도0이었지만,
그 사실만으로 실제 모터 토크 여유나 필요한 접지 동작을 보장하지 않는다.

## 다음 단일 변수 시험 — 실행 중

회전 명령과 직진 명령의 학습 분포를 분리한다. 같은 yaw16 모델·정규화에서 출발,
seed0, 환경4개, 추가500,000 스텝 목표(실제 PPO 배치 반올림은 완료 후 기록).

- 대조: `turn_curr_control7_20261009`, 명령범위 `[7,.3,1]`
- 비교: `turn_curr_focus4_20261009`, 명령범위 `[4,.3,1]`

실제 프로세스와 설정은 runs/screen_logs/<이름>.process.json, 학습 로그는 같은 이름.log.

4 m/s에서만 회전하고7 m/s 직진을 잃는 정책도 통합 후보로 채택하지 않는다.
이번 비교는 학습 분포 가설이며 이미 입증된 원인으로 기록하지 않는다.
