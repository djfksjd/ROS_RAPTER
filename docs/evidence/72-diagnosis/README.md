# 72 — Gazebo 빠른 보행 roll 전도 진단 (2026-09-28, 1단계: 진단만, 제어 코드 변경 없음)

사용자 지시: 꼬리 작업 동결(c2c1b03). 넘어짐 원인을 코드 수정 전에 진단하고, 가설 3개 이내를 보고한 뒤 멈춘다.

## 방법

- 보행: digitigrade, crouch -0.10/0.50, A 0.08, **2.5Hz, stride 0.08**, 발목 pitch 피드백 (0.5, 0.05, 0.15), **꼬리 고정**.
- Gazebo: `rock_gz_probe.py --diag`(기록 전용: 100Hz 관절·IMU·접촉 wrench) + `gz topic -e .../dynamic_pose/info`
  (링크 자세는 모델 기준 → 월드 변환, CoM은 URDF 질량으로 계산). 3회 실행.
- MuJoCo: 같은 보행, JTCLikeServo(0.02, 0.02), kv 20/30/100. `rock_probe.run(step_hook=...)`로 같은 항목 기록.
- 분석: `sim/roll_diagnosis.py`(두 엔진 같은 계산). 발 위치 = 발 패드 중심, XCoM = CoM y + vy/√(g/z).
- 파일: `report.json`(구간 통계), `timeseries.json`(5.0~6.5초, 전도 직전 1.5초), `*.png`(나란히 비교),
  `gazebo-raw-logs.tar.gz`(원본 3회).
- 시간 t는 probe 시작 기준 sim time(1초 정지 + 1초 ramp 후 보행). 명령 전송 간격은 sim 0.021초로 일정(지연 흔들림 없음).

|---|---|---|---|---|

| Gazebo 2 | 3.31초 기울기 0.261 | 왼쪽, roll -0.245, CoM y 0.169 | -0.245..0.148 | 0.30 / 0.40 |
| Gazebo 3 | 4.51초 기울기 0.253 | 왼쪽, roll -0.238, CoM y 0.151 | -0.238..0.152 | 0.32 / 0.37 |
| MuJoCo kv20 | 7.89초 | **pitch**(roll 0.014), CoM y 0.088 | - | - |
| MuJoCo kv30 / kv100 | 넘어지지 않음 | - | ±0.07 / ±0.075 규칙적 | 좌우 비슷 |

- **방향**: Gazebo는 3회 모두 **왼쪽**으로 넘어졌고, 오른발 하중 비율이 매번 낮았다.
- **누적 vs 급변**: 매 걸음 누적되지 않는다. 주기별 roll 최대값은 ±0.12~0.15로 추세 없이 불규칙하다가,
  마지막 **2~3걸음(약 1초)** 동안 XCoM이 -0.15 → +0.22m로 한쪽으로 흘러가며 급격히 커진다. 그동안 오른발이 다시
  받치지 못한다(1회차 마지막 약 0.6초 오른발 수직력 0).
- **저주파 흔들림(핵심)**: 정상 보행 중에도 Gazebo 몸통은 명령 2.5Hz를 따르지 않고 **약 0.9Hz(3걸음 주기)**로
  좌우로 흔들린다(2~6.5초, CoM y):

  | | 주성분 | 0.3~1.6Hz 진폭 | 2~3Hz 진폭 |
  |---|---|---|---|
  | Gazebo 1 | 0.89Hz | 0.103m | 0.005m |
  | MuJoCo kv100 | 2.44Hz | 0.005m | 0.011m |
  | MuJoCo kv30 | 0.89Hz | 0.044m | 0.012m |
  | MuJoCo kv20 | 0.67Hz | 0.092m | 0.008m |

  MuJoCo는 서보가 약할수록(kv 낮을수록) 같은 저주파 성분이 커지고, kv20에서는 Gazebo 수준이 되어 넘어진다(단 pitch).
- **미끄럼**: 하중 발 패드 수평 속도 p90이 Gazebo 0.07~0.12m/s, MuJoCo 0.05~0.12m/s로 비슷하고 전도 직전에 늘지 않았다.
  **미끄럼은 주원인이 아니다.**
- **힘**: 하중 발의 옆/수직 힘 비 p90이 Gazebo 0.33~0.41, MuJoCo 0.23~0.28. Gazebo 수직력은 10~20ms 간격 톱니
  진동과 힘 0 접촉 메시지가 섞인다(접촉 계측·강체 접촉 특성).

## 원인 가설 (3개)

1. **고관절 roll 구동의 유효 강성·지연 부족 → 0.7~0.9Hz 측방 sway 모드가 억제되지 않음** (가장 유력)
   - 근거: Gazebo hip roll은 하중 상태에서 명령보다 작고 늦다(0.88, 64ms). MuJoCo에서 kv를 낮추면 같은 저주파
     성분이 커지고(kv100 0.005 → kv30 0.044 → kv20 0.092m) kv20은 넘어진다.
   - 반대 근거: MuJoCo kv20은 pitch로 넘어져 roll 전도를 그대로 재현하지는 않는다.
   - 확인안: MuJoCo kv20~30 + 명령 지연 추가로 roll 전도가 재현되는지, Gazebo hip roll 하중 계단 응답 측정.
2. **접촉 모델 차이(강체 LCP·피라미드 마찰 vs 연성 접촉·타원 원뿔)로 패드 모서리 흔들림 감쇠가 작음**
   - 근거: Gazebo 수직력 톱니 진동, 옆/수직 힘 비가 1.5배.
   - 확인안: MuJoCo 접촉을 더 딱딱하게(solref 0.005)·pyramidal로 바꿔 sway 성분 변화 확인.
3. **보행 자체의 좌우 비대칭 + 측방 착지 보정 부재 → sway가 한쪽 전도로 전환**
   - 근거: Gazebo 3회 모두 오른발 하중이 적고 모두 왼쪽으로 넘어짐. 발 착지 y는 고정(±1.5cm)이라 커진 sway를
     받아 줄 걸음이 없다. MuJoCo kv30에서도 CoM이 -0.03m(오른쪽, Gazebo와 반대) 치우친다.
   - 확인안: stride 창 위상(0.28/0.78)을 좌우 뒤바꿔 전도 방향이 바뀌는지, 2단계 (a) 착지 보정으로 막히는지.

가설 1과 3은 서로 배타적이지 않다. 1이 흔들림을 만들고 3이 그것을 한쪽 전도로 바꾸는 구조일 수 있다.
