## 계측의 실제 범위

각조건off/on전체raw행은정확히같고156원행과도같았다. 성공83002는60초통과,86013은.70초전도다. 이계측은그궤적을바꾸지않았다. 근처초기속도여도초기관절상태/높이/접촉분포는다르므로속도가유일한원인이었다고해석하지않는다.
