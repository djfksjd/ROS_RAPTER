## 실제 계측과 재현

원시작의 무릎–발목/발목roll equality 오차 최대값은 .01909–.05452rad다. 첫 순간 전체 외부 지면반력은0인데 무릎 수동 토크는 약−77.49~−93.37Nm였다. loaded 플래그는 reset에서 양쪽 True이고 첫20ms의 latch 연결에 반영된다. 최초 .2초 최고 수직 지면반력은4.630–5.225BW다. 이는 이 시작조건/제어에서의 순간 하중이고 달리기/실물 충격 사양이 아니다.

원조건 계측 off/on의 전체 qpos/qvel/action/기울기/비행 로그가 정확히 같았다. 새 모델마다 반복한 원조건의 모든 행동은153 원시작4회와 정확히 같았다. 따라서 계측 때문에 실패가 발생한 것으로 보이지 않는다.

최초 history-sensitive 버전에서 초기 audit 스프링 강성/수동 토크가 이전 시험 종료 상태에 따라 달라지는 것을 발견했다. 해당 원값은 보존하고 최종비교는 fresh 버전(매시험 새 모델)으로 다시 수행했다. 첫 physics step의 연결값은 별도로 기록했다. history-sensitive 버전의 초기 qacc/수동 토크 차이를 연동 투영의 효과로 해석하지 않는다.

## 전환 조건에서 발견한 결함

평형 목표 접근은 고정 u_reference를 사용하고 실제 실행한 입력으로 추정기의 예측을 보정했다. 국소 전환 조건은12관절 오차≤.08rad, 관절속도≤2rad/s, 중력 방향 벡터 오차≤.1, 몸통속도≤.5m/s다. 관절 기반 조건만 사용한4회는 모두 .14/.16초 공중에서 진입했다(실제 지면반력0). 진입 순간 수동 지지 발가락 최대 오차는 약 .0775–.0776rad였다. 단순 관절 근접이 양발 지지 국소영역을 의미하지 않는다는 직접 증거다. 수동 발가락 오차가 이후 전도의 단일 원인이라고 증명한 것은 아니다.

양쪽 발 실제 수직 하중≥.15BW 조건을 추가한 비교에서는 seed83001만 .32초에 진입, 나머지는 진입하지 않았고4회 모두 전도했다. 이 gate는 기존46관측 외에 시뮬레이터 접촉힘을 읽는 진단이다. 순수46관측 운영 제어 또는 실물 센서가 완료됐다는 주장으로 승계하지 않는다. gate만 고쳐 원시작→기립을 해결하지 못했다.
