# 99 — 고관절 roll 목표 범위 비교

카탈로그 정책 `seq_compare_catalogue_20261009`의 목표 범위만 ±0.3 / ±0.45 rad로 비교했다. 실제 관절 한계 ±0.5 rad·8축·구동기·질량·정책 가중치는 동일하다. 재학습 없이 출력 배율만 바꾼 진단이다.

각 범위에서 3개 출발 × 6조건 = 18회. ±0.3은 전도 0/18, 회전 통과 0/12. 회전 구간 두 고관절의 명령 포화 비율은 모두 0; 추종 RMS는 약 0.046–0.070 rad다. ±0.45는 18/18이 회전 시작 4초 전에 전도했다. 출력 범위 확대는 미채택이며, 8축 구조의 회전 불가능을 증명하지 않는다.

원본 `roll_range_20261009.jsonl`에는 회전 전 전도 때문에 측정 구간이 비어 통계가 NaN인 행이 있다. 물리 결과는 보존했다. `roll_range_corrected_20261009.jsonl`은 재실행 없이 같은 원본의 계측 통계만 수정했다. 빈 구간은 measured_samples=0, 통계=null로 기록하고 strict JSON으로 검증했다. 계측 부재를 0 오차로 해석하지 않는다.

다음 한 단계: 기존 지수 속도 추종 보상이 정지 직후 큰 오차를 거의 구분하지 못하는지 확인하고, 선택적 선형 속도 오차 보상을 대조군과 비교한다. 기본 보상과 기준 모델은 보존한다.
