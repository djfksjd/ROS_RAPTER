### 불일치 해소 (계측 기준)

- 진단 72의 0.005m는 **Gazebo CoM y의 2~3Hz 대역 진폭**(Hann FFT, 대역 RSS)이다. 이 표의 "몸통 중심 y"는 base_link 원점이다.
- 예측식은 양쪽 hip roll이 다리를 기울여 몸통이 옆으로 **평행 이동**한다고 가정한다. 그러나 발목 roll 축이 없어
  평평한 발바닥이 다리 기울기를 막으므로, 같은 명령은 주로 **몸통을 굴린다**.
  - 측정 몸통 roll은 A에 비례한다: kv30 0.78A, kv100 1.08A, Gazebo 0.96A(진단 72).
  - 몸통 옆이동은 A와 무관하게 1~1.6cm이고, A = 0(kv100)에서도 1.5cm다.
  - Fy/Fz는 A와 무관하게 0.24~0.37이다.
- 예측 대비 편차: 옆이동 −76%(A 0.08, kv30), Fy/Fz −85%. **20% 기준 초과 → 정지.**

## 실행하지 않은 것 (규칙에 따라 정지)

- 실험 A의 Gazebo 부분(5진폭 × 3회), 실험 B(스윙 폭), C(착지 폭), D(지연 분해).
- 실험 D 주의: gz_ros2_control 1.2.20 `gz_system.cpp` 797-804행은 `target_vel = -position_proportional_gain × (q − q_cmd) × update_rate`
  (update_rate = controller_manager 갱신률 100Hz)라서, 샘플 주기 10 → 1ms
  (갱신률 100 → 1000Hz)는 유효 이득을 10배 올린다. 이득 상향 금지를 지키려면 position_proportional_gain을
  0.3 → 0.03으로 같이 낮춰야 한다(곱 30/s 유지). 실행 전 확인이 필요하다.
