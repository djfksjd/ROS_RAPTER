# 116 — PPO 추가 학습 구간별 회전 퇴행

동일한 frozen `sym_init_20261009`에서 기존 random-command·seed0·4환경·보상·물리·46관측·8출력 설정으로 각각 16,384와65,536스텝을 학습했다. 두 실행과 각12회 평가가 정상 종료했다. 학습 설정·완료 기록·progress·원 평가·로그·모델 해시를 보존한다.

같은 개발용 출발66001/66002를 재사용한 진단이다. 115의 초기/4k 회전량8/8에서16k는6/8,64k는0/8로 퇴행했다. 두 단계 모두전도0/12다. 회전구간 최소속도3.6m/s 조건은16k0/8·64k3/8로, 회전량만으로 통합목표를 달성하지 않았다. 16k실패는+0.5 두출발,64k는네회전조건 모두다. 독립최종평가·60초발열·기립·정지 검증은 이번에 수행하지 않았다.

CSV의 PPO KL은 약0.02 수준이 관측되지만 이것만으로 퇴행 원인을 확정하지 않는다. SB3는 학습 전 로그를 출력하므로 마지막행 train지표는 최종업데이트 전 값이다. `clip_fraction`은 정책확률비 clipping이며 기계관절포화가 아니다. explained_variance가 양수인 기록에서 critic전체붕괴를 주장하지 않는다. 훈련보상은 VecNormalize 정규화, 평가보상은 raw이므로 value와 rawreturn을 같은단위로 비교하지 않는다.

다음 개발 단계는 업데이트 폭의 영향 분리다. 선택형 target_kl을 도입한다면 기본None을 보존하고 동일조건 대조와 비교한다. SB3 target_kl은 임계초과시 추가optimizer단계를 중단하는 장치이며 이미 수행한 업데이트의 KL상한을 보장하지 않는다. 새 변경/실험은 아직 수행하지 않았다. 기준선 및 실패 모델 미교체, goal active.
