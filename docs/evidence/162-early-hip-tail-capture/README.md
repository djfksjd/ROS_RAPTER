161의 원시작 초기구간 실패를 개선하기 위해 원8축 기구, 구동곡선, 관측46개, 원reset와 기립gate를 유지하고 초기 .6초에만 관측 기반 보정을 대조했다. 기준선 미교체·후보 미채택·goal active다.

## 속도 좌표와 반응 교정

현재 관측 속도는 free-root의 선형속도를 base_link 좌표로 회전한 값이다. base_link는 root에서 [0,0,.58]m 떨어진 고정 자식이므로 몸통 지점 속도는 v_point=Rᵀv_root+ω×offset이다. 부모/고정회전 확인과 세 상태 mj_jacBody 속도 대조의 최대차이는4.16e-17m/s였다. 이는 좌표식의 검사이며 실제 센서 속도추정 또는 기존 성공metric을 수정한 것이 아니다. 온라인 계산은 기존 관측의gyro/속도와 고정 offset만 사용했다. 반환 관측의 기존1ms 타임스탬프 특성은 유지한다.

158의 성공83002와 실패86013, .02/.10초 실제 저장 상태를 복원한 오프라인 pulse대조24회에서는 양쪽 hip normalized−.025와 tail+.09375를 함께 넣을 때 몸통 지점 전방속도가 baseline보다약.0397–.0411m/s 감소했다. .10초 pitch각속도 변화는약+.0142/+.0153rad/s로 단독hip보다 작았다. .02초 실패조건은−.1249rad/s 변화로 상쇄가 정확하지 않다. 네 상태 국소반응이며 전체 궤적·기계적 안정성의 증명이 아니다. 초기화에 실제 시뮬레이터 상태를 사용한 오프라인 교정과 온라인 관측기 제어를 구분한다.

## 접촉 계측으로 배제한 가설

대조와 paired pitch-only의83002/86013을 각1ms 계측해4회 재생했다. 20ms rows는 계측 전후 정확히 일치했다. force_time은 state_time−.001이며 힘은 preintegration 접촉 계산값, q_after는 postintegration 값으로 따로 기록했다. PD요청토크를 당시forcerange로clip한 값과 실제토크의 최대차이는1.60e-13Nm였다.

.24–.32초 구간에서 기존대조는 두조건 모두 양발지면반력0인 순간이0ms였다. paired pitch-only는83002에서34ms,86013에서43ms로 늘었다. 이 구간 수직충격량 합은대조3.0424/3.2765N·s에서paired .5604/.8137N·s로 줄었다. 계측한 첫.6초의hip/tail torque포화는 두조건/두모드 모두0이었다. 따라서 이 비교의 새 접촉이탈을 hip/tail구동포화 하나로 설명할 수 없다. 접촉이탈 이후 자세·추정 오차가 커질 수 있지만 단일인과로 단정하지 않는다. hip/tail토크 산술합은 자유몸통의 순모멘트와 같지 않다.
