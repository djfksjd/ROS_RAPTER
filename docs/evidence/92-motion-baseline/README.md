정지는직전 실제 평면 속도≥3.6m/s, 명령후3초 이내속도norm<0.1m/s를0.5초 유지,

네 전환시험 모두주행 구간의 후기 속도는4명령을 추종했지만, 초기기립·걷기·정지 조건은 실패했다.
