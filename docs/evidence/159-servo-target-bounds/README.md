# 159 — 구동 한계 기반 servo target 제한

158의첫전환구동포화에대해관측q/qd와원모터curve로목표각범위를제한했다. q=q0+obs[12:24], qd=obs[24:36]/.05이며모터별기어/원torque-speed/drive-brake곡선과1.6초이후cap.995를사용한다. 원곡선/기구/행동수/원시작/기립조건을바꾸지않는다.

## 구현과 범위

PD요청τ=kp(target−q)−kd*qd를뒤집어target_low=q+(τ_low+kd*qd)/kp, target_high=q+(τ_high+kd*qd)/kp를계산하고물리normalized행동범위와교차한다. 빈교차는flag와가장가까운물리경계목표를반환한다. 실제실행입력과proposed입력의차이를B로추정기prior에반영한다. 순수NumPy limit_servo_action은환경이나수동관절실제값을읽지않는다.

이는현재관측시점의PD요청경계다. 실제20ms목표ramp/가변기어/속도/접촉이변하므로전체주기의포화를없앤다는보장은아니다. 기존physics곡선은매1ms실제토크를계속제한한다. 구동능력상향·실물안전기능인증으로보고하지않는다.

원성공83002는60초통과와전체3000공통raw필드를그대로유지했다. 실패86013은.70초에서.90초로종료시간이달라졌으나기립실패이며전체위치/기울기/비행기준을충족하지않았다. 계측off/on행이정확히같았고1ms요청PD토크를실제curve로clip한값이실제actuator_force와허용오차내일치함을확인했다.

## 국소 예측모델의 검증 범위

158저장상태의.58/.60/.62초에서fullqpos/qvel/이전목표를복원하고실제로실행된다음입력을넣어20ms전이를예측했다. 기존A/B/f0의선형예측과같은물리구성의LocalStandModel.transition을비교했다. 각6개전이에서비선형예측오차의rawstate norm은약8.8e-9~1.3e-5였고,선형예측오차는약.357~16.64였다.

rawnorm은위치/각도/속도/이전normalized입력이섞인진단량이며물리오차단위나전체성능percent가아니다. 상대값도실제한주기state change norm에대한비율로만저장했다. 비선형결과는원시뮬레이터실제상태로초기화한오프라인검증이며,기존46관측의추정상태에서그만큼맞는다는증명이아니다. 실제부품/Sim2Real정확성도증명하지않았다. 이비교는전환상태에서국소선형예측을그대로믿기어렵다는근거다.
