# 81 — MuJoCo 정책의 Gazebo 실행과 이식 판정 (2026-09-29)

`rl_policy_node.py`가 내보낸 정책(`src/raptor_control/policies/*.npz`, numpy 추론)을 Gazebo Harmonic(DART, 12축,
평평한 패드)에서 50Hz로 실행했습니다. 감시기: 기울기 0.6rad, 입력 끊김, 속도 포화 지속, 시계 이상 → 자세 유지 후 종료.

| 정책 / 조건 | 결과 (넘어진 시각, 이동) |
|---|---|
| 평지 정책, 제한 없음, 포화 0.2초 감시 | 0.8초 무릎 포화로 정지 |
| 같은 정책, 포화 0.5초 허용 (`sat05`) / JTC 10ms (`h01`) | 2.2초 / 4.2초 (0.46m) |
| kv 20~150 무작위화 학습 (`robust_a/b`) | 6.8초 (뒤·옆 2.6m 흐름) / 4.2초 |
| + 목표 속도 제한 0.85 (`slew_03/00`) | 4.2초 (0.93m 전진) / 8.3초 (옆 2.2m 흐름) |

## 원인 조사

- **속도 포화:** 제한 없는 정책은 목표를 6~21rad/s로 움직였습니다(한계 2~3). 무릎은 75% 시간 포화, 발목 pitch는 0.7rad 한계까지
  갔습니다(DART 포화 결함, 증거 61). 목표 속도 제한 뒤 무릎 포화는 5~11%로 줄었습니다.
- **서보 강성:** MuJoCo에서 같은 정책이 kv ≥ 60에서 넘어졌습니다(kv 100에서 2.6초). DART 서보는 빠른 동작에서 kv 30보다 딱딱합니다.
- **IMU 계약:** 쿼터니언 변화로 계산한 각속도와 측정 각속도가 두 엔진 모두 일치합니다(Gazebo 상관 0.95~0.98, 이득 0.92~1.0).
  관측의 좌표·부호에는 문제가 없습니다.
- **재생 비교:** Gazebo 목표 순서를 MuJoCo에 그대로 재생하면 관절 차이는 0.02~0.09rad RMS인데, 몸통 각속도는 0.1초 안에 달라집니다.
  관절이나 서보가 아니라 접촉(발 패드·수동 발가락·마찰 모델)에서 갈라집니다.

## 판정 (Fable 검토)

Gazebo(DART)로의 동역학 이식은 **통과 기준으로 삼지 않습니다.** 시뮬레이션 방법론(DART는 동역학 기준이 아님, 모터 미선정)에 따라
MuJoCo를 동역학 기준으로 쓰고, Gazebo는 ROS 통합·STOP 경로와 보수적 걸음의 감시기 무작동 여부만 확인합니다.
관측·행동 계약 버그 여부는 확인했습니다(IMU·관절 순서·정책 출력 일치).

다음 학습(`--dr 2`)에 반영한 것: 발목 pitch 목표 ±0.55rad(관절 끝에서 0.15rad 여유), 관측 잡음과 0~40ms 지연, 발가락 스프링 ±50%,
무게중심 ±3cm, 몸통 무작위 힘 펄스, 초기 속도 ±0.2m/s, kv 20~200, JTC 20ms, 목표 속도 제한 0.85.

**Gazebo에서 걷기는 아직 성공하지 못했습니다.** 이 결과를 보행 성공으로 보고하지 않습니다.
