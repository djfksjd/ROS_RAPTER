# 108 — 명령별 보상·접촉 분포 계측

106의 대조/loaded후보 최종 모델을 새출발 seed53001, 기립8→걷기0.4(6초)→직진4(8초)→yaw+1(4초)→yaw−1(4초)→정지13초 순서로 각43초 실행했다. 각모델 계측off/on 한쌍 총4rollout. 실제행동·qpos·qvel·reward 정확일치, 전도0. 반환 info.terms를 읽었으며 보상함수를 다시 호출하거나 물리 상태를 고치지 않았다. 매스텝 가중합×0.02와 실제 보상의 일치를 확인했다. 원시값과 스크립트를 보존했다.

기립/정지의 대부분은 한쪽만 loaded로 분류됐다. loaded 기준은 해당발 지면반력>0.15BW로, 접촉면 존재 자체와 다르다. `stand=float(flight)`는 양발이 모두 unloaded일 때만 벌점을 준다. 따라서 이 모델의 영점명령에서 번갈아 단발지지하는 결과에는 대부분 stand벌점이 없다. `gait_schedule`은 전진명령0.5미만에서 꺼지고, `progress`는 영점명령의 앞으로움직임을0으로 자르며 후퇴에만 음수다. 선형속도 추종은 양방향 오차를 여전히 벌주므로 앞으로 이동을 직접 보상한다는 결론은 아니다. 고정 위치/양발지지/관절정지의 명시항은 현재 없다.

회전에서 yaw 추종 가중보상은 /s 대조9.32/9.74, 후보8.20/8.53. angular momentum벌점은 −0.147/−0.230, −0.090/−0.113으로 이 표본에서 yaw추종 이득을 압도한다는 설명은 지지하지 않는다. 항별 평균만으로 최적 행동·기울기·학습인과를 증명하지 않는다.

다음 최소 비교는 전진·측방·yaw 명령 모두 영점인 정차 조건에서만 unloaded발 비율의 선택적 벌점을 추가하는 것이다. 기본가중치 미설정 시 항목·보상·동역학 정확히 유지, 회전/이동명령에 항목0, 관측/행동/기구 unchanged를 먼저 검증한다. 이후 동결 카탈로그 source에서 가중치0/음수 한항 대조학습과 원래의 회전·직진·열·기립·정지 기준 전부로 평가한다. 아직 구현/학습하지 않았다.

연구 근거: [Gait-conditioned RL §III-D/F](https://arxiv.org/html/2505.20619v1)은 보행모드별 보상 routing, 정차의 양발지지·움직임 억제를 구분한다. 23축G1/LSTM 연구의 아이디어이며 랩터8축의 직접 성공 증거나 동일 설정으로 적용되는 처방은 아니다.
