# 74 — 흔들목마 모델 1단계: 실험 F에서 예측 이탈로 정지 (2026-09-29)

사용자 기준(교체된 모델): 디딤 다리는 땅에 박힌 기둥, hip roll은 몸통을 굴린다. 흔들림 반주기 ≈ 단일 지지 0.19s,
실험 F 예측 "뜸 → 반대 발 닿음" 0.17~0.26s, 그 2배가 고유 걸음 주기. 순서 F → E → C → D, 20% 이탈 시 정지.
금지 유지: 서보 이득 상향, 접촉 모델·솔버 변경, 꼬리(c2c1b03) 변경. 꼬리 고정.

## 실험 F — 방법

- 명령: `rock_law.step_roll` — 웅크린 자세에서 hip roll r을 **1.6rad/s**(한도 2.0의 80%, 명령 속도 검사 통과)로
  +0.08까지 올리고 0.5초 유지 후 0으로. 3초 뒤 −0.08로 같은 동작. 좌 hip roll = −r, 우 = +r.
  계단 명령은 명령 속도 검사(한도 90%)에 걸려 쓸 수 없다.
- 판정: 발 수직력 < 5% 체중 = 뜸, ≥ 20%가 20ms 유지 = 착지.
  - Gazebo는 50Hz 접촉 메시지에 힘 0 메시지가 섞여 10ms 격자에서 직전 30ms 최대값을 썼다.
- MuJoCo: JTCLikeServo(0.02, 0.02), kv 20/30/100(`sim/lateral_experiments.py F`).
- Gazebo: `rock_gz_probe.py --step-roll 0.08 0.5 --diag` 3회.
- 파일: `expF_mujoco.json`, `expF_gazebo.json`(곡선 포함), `expF_roll_and_forces.png`, `expF-gazebo-probe-logs.tar.gz`.

### 첫 착지 뒤 자유 흔들림 (0~3s)

| 조건 | 이어지는 한 발 지지 시간(연속) | 0.5s 구간별 \|roll\| 최대 |

- 자유 흔들림은 **감쇠하는 흔들목마(rocking block) 운동**이다. 진폭이 줄수록 한 발 지지가 짧아진다
  (Gazebo 0.63 → 0.32s). 하나의 고유 주기가 아니다.
- Gazebo 최대 진폭 부근 한 주기 ≈ 0.63 + 0.56 ≈ 1.2~1.3s(≈ 0.8Hz). **진단 72의 0.8~0.9Hz 저주파 흔들림과 같은 대역이다.**
- 감쇠: Gazebo는 0.5s마다 약 ×0.75로 느리게 줄어 3s 뒤에도 흔들려서, 두 번째(−) 이벤트가 양발 딛은 상태에서
  시작하지 못했다(Gazebo 이벤트 2는 판정 제외). MuJoCo kv30은 약 1s, kv100은 약 2.5s 안에 멈춘다.

## 판정과 정지 이유

1. 첫 뜸 → 착지: Gazebo·kv100은 예측 안, kv30은 −12% 이내, **kv20은 −21~−40%로 20% 기준 초과.**
2. "F 값의 2배 = 고유 걸음 주기(≈ 2.6Hz 공진 근처)": 자유 흔들림의 반주기는 진폭에 따라 0.3~0.64s다.
   최대 진폭 부근 주기는 약 0.8Hz로, 예측(1.9~2.9Hz)과 **100% 이상** 다르다.
3. 규칙에 따라 여기서 정지. **실험 E, C, D는 실행하지 않았다.**

## 관찰 (가설 아님, 다음 판단용)

- 2.5Hz 개루프 흔들기는 자유 흔들림(대진폭 ≈ 0.8Hz)보다 훨씬 빠르다. 저주파 흔들림은 이 자유 흔들목마 모드가
  Gazebo에서 덜 감쇠되어 남는 것과 일치한다.
- 첫 강제 흔들림의 크기(roll 0.13)와 감쇠율이 Gazebo와 MuJoCo kv100에서 비슷하다. kv가 낮으면 흔들림이 작고
  빨리 멈춘다. MuJoCo 서보(kv)가 흔들림에 감쇠를 더한다는 72의 가설 1과 방향이 맞다.

# 74 (계속) — 교정 모델, 실험 E·D·C, 2단계 (2026-09-29)

## 교정 모델 — 흔들목마(Housner), 피벗 = 디딤 패드 바깥 모서리

- CoM 0.758m, 피벗 y 0.23(0.18 + 패드 반폭 0.05): α = atan(0.23/0.758) = 0.295, R = 0.792, p = √(g/R) = 3.52/s.
- 반주기 T½(θ) = (2/p)·acosh(1/(1−θ/α)). Gazebo F 자유 흔들림(θ 0.039~0.13)과 **−5~+7%**. 패드 중심 피벗은 +10~+30%.
- n:1 잠김(착지가 시계의 n/2 주기마다): T½ = n/(2f) → θ, CoM 진폭 ≈ R·cosα·θ.
  - n = 3: 2.5Hz → 0.085m(72 Gazebo 보정값 0.084m와 일치), 2.2 → 0.100, 2.0 → 0.112.
  - n = 1: 2.5Hz → 0.013m.

## 하드웨어 대안 (근거만 기록, 구현하지 않음 — 사용자 지시 (d))

- **발목 roll 1축 추가(다리당 +1, 능동 12축):** 발바닥을 땅에 평평하게 둔 채 다리를 기울일 수 있어, 착지 폭 조정(착지 보정)과
  발바닥 각도 기준을 동시에 만족할 수 있다. 실험 A·C에서 "hip roll은 몸통을 굴릴 뿐 다리를 기울이지 못한다"는 제약이 이 축의 부재에서
  나온다. 10축 불변 조건 변경이라 사용자 결정 사항이다.
- **둥근(원통형) 패드:** 패드 모서리 대신 곡면으로 굴러 흔들목마의 충돌 손실과 모서리 접촉(발바닥 각도 급변)을 줄인다.
  발바닥 각도 기준을 "패드 곡률 안의 굴림"으로 다시 정의해야 하고, 정지 지지 여유가 줄어든다.

## 다음 결정 사항

1. Fy/Fz ≤ 0.4(Gazebo 0.405~0.422)와 착지 발바닥 ≤ 0.02(음의 외전 시 0.05)의 맞바꿈: 기준 조정, 음의 외전 채택, 또는 하드웨어 대안.
2. MuJoCo kv30 착지 발바닥 0.032~0.041(Gazebo 0.015): 엔진 차이로 기록할지 여부.
3. kv20(연한 서보)는 긴 램프에서도 7~8s 전도 — actuator 사양 범위가 정해지면 다시 평가.
