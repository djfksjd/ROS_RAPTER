## 후속 탐색 분산 비교 — 완료·미채택

저장된 yaw16의 Gaussian 행동 표준편차는 축별0.0474–0.1273이었다.
평균 정책이 이미 학습한 작은 회전 주변에 머무는 가설을 탐색한다. 낮은 분산 자체를 실패의 확정 원인으로 주장하지 않는다.
`--resume-action-std`는 명시적으로 준 경우에만 학습 탐색 분산을 재설정한다. 기본은 기존 분산을 유지한다.
저장 모델의 결정적 행동이 같고 log_std 외의 모든 정책 파라미터가 같음을 실제 모델에서 검증했다.

같은 원 yaw16 모델·정규화·명령[7,.3,1]·seed0에서 각각500,000 추가 스텝 목표:
`turn_explore_control_20261009`는 기존 분산,
`turn_explore_std25_20261009`는 모든 행동의 시작 std0.25.
학습 optimizer 상태와 배우는 평균 네트워크는 유지한다. 이 분산은 학습 중 다시 변할 수 있다.
실제 설정은 runs/<이름>/initial-policy.json과args.json, 프로세스는 screen_logs/<이름>.process.json.
완료 후 출발별 회전·4/7직진·발열 및전도 검사를 같은 기준으로 비교한다. 후보 채택은 아직 없다.
