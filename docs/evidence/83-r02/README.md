# 83 — 낮은 자세와 R-02 재설계 모델의 첫 학습 (2026-09-29)

사용자 결정: 무게중심을 낮춤(발목 ±1.0 변형 + 깊은 웅크림), 이후 수학적 전면 재설계 R-02([DESIGN_R02](../../DESIGN_R02.ko.md)).
모두 MuJoCo 결과이고, 보행 성공이나 실기 성능이 아닙니다. 원자료: `eval.json`.

## 1. 낮은 자세 (기존 몸, 발목 ±1.0, 기준 자세 고관절 −0.8 / 무릎 1.65 / 발목 −0.85)
- 정지 기립 10초 유지. 무릎 정지 토크 6.4 → 16.4N·m(한도의 14%).
- lowA(B4에서 이어 학습, 300만 스텝): 평지 0~0.6m/s 넘어짐 0, 추종 오차 0.13~0.16.
  보행 중 무게중심은 0.700m로 B4(0.741m)보다 5.5%만 낮았습니다. 보상의 높이 항이 낮아짐만 벌하고 높아짐은 허용했기 때문입니다.
- lowA2: 높아짐 벌점(`tall`, 기준 높이 +2cm 초과) 추가 → 보행 중 무게중심 **0.660m**(B4 대비 −11%).
  기본 무작위화 0/48, 20N 펄스 0/48.

## 2. 발 구조 비교 → 형상 문제 발견
- 기존 발은 걸을 때 **평평한 발판이 하중의 85~89%**, 발가락은 11~15%만 받습니다.
- 무게중심이 발가락 뿌리(MTP)보다 6.7cm 뒤에 있어, 발판을 줄인 타조형 발은 발가락 강성(12~144N·m/rad)과 무관하게 0.7초 만에 넘어졌습니다.
- 이 문제는 발가락 변경으로 풀 수 없어 다리 전체 재설계로 넘어갔습니다. 변형 모델: `sim/foot_variant.py`.

## 3. R-02 모델 (`modeling/build_r02.py`, 11.36kg)
- 두 발가락으로 설 때 하중: 발가락 III 80%, IV 20%. 타조(78/20)와 같습니다.
- 제어 없이는 약 1초 만에 앞으로 넘어집니다. 관절을 모두 잠가도 넘어졌는데, 원인은 다음과 같습니다.
  - MuJoCo 관절 한계가 부드러운 제약이라 하중에서 0.03~0.06rad 휩니다.
  - 그 결과 Z자 다리가 앞아래로 접히는 모드가 생깁니다.
  - **발가락으로 서는 몸은 능동 균형이 필요합니다.** 타조·Cassie도 같습니다.
- 넘어짐 판정을 절대 높이 0.5m에서 `min(0.5m, 기준 높이의 75%)`로 바꿨습니다. R-02 몸통은 약 0.58m라서 웅크리자마자 넘어짐으로 판정되던 결함이었습니다. 기존 모델의 판정은 그대로입니다.
