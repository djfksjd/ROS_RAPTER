# 78 — 강화학습 기준선과 보상 결함 (2026-09-29)

## 10축 평지 기준선 `walk_flat_v3` (400만 스텝, 무효 판정)

| 명령 vx | 넘어짐 | 평균 몸통 속도 | 추종 오차 |
|---|---|---|---|
| 0 / 0.1 / 0.2 / 0.3 m/s | 0/4 · 0/4 · 0/4 · 0/4 | −0.51 / −0.50 / −0.42 / −0.43 m/s | 0.90~1.06 m/s |

넘어지지 않았지만 명령을 전혀 따르지 않았습니다. 뒤로 움직이며 몸을 돌렸습니다(20초에 yaw −2.6rad). **보행 성공이 아닙니다.**

## 원인 (확인됨)

- 속도 추종 보상에 자유 관절의 선속도 `qvel[:3]`를 썼습니다. 자유 관절 원점(base_root)은 몸통(base_link)보다
  0.85m 아래에 있어서, 몸통이 기울어질 때마다 가짜 속도가 섞였습니다. 예: pitch 0.8rad/s → 원점과 몸통의 속도 차이 0.68m/s.
  추종 보상이 잡음 때문에 거의 0이었고, 정책은 버티는 법만 배웠습니다.
- 발 미끄럼 항은 `cvel`(트리 무게중심 기준 공간 속도)을 발 속도로 잘못 썼습니다.
- 수정: 몸통·발 속도를 `mj_objectVelocity`(무게중심 기준 월드 좌표)로 구하고 몸통 자세로 회전합니다. MuJoCo의 local 옵션은
  관성 주축 좌표라 쓰지 않습니다. 회귀 테스트: `tests/test_rl_env.py::test_base_velocity_is_the_torso_velocity_in_its_frame`.

이 결함 때문에 v1~v3(10축) 결과와 첫 12축 학습은 속도 추종 판단에 쓸 수 없습니다. 12축 학습 `walk12_flat_v2`를 수정된 보상으로 다시 시작했습니다.
