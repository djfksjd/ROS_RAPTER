# 132 — 동결된 저학습률 후보의 입력 보정 2×2 비교

131 모델을 재학습하지 않고 회전 입력 배율 1/1.1과 속도 입력 피드백 off/on을 분리 비교했다. 개발 초기상태 71001·71002, 실제 환경 목표는 4 m/s와 좌우 ±0.5/±1 rad/s, 회전 구간은 4–6초로 유지했다. 정책에 전달하는 입력만 바꾸며 관절·접촉·토크 한계와 보상은 변경하지 않았다. 임시 진단 코드를 함께 보존했다.

| 회전 입력 배율 | 속도 피드백 | 각도 통과 /8 | 속도 통과 /8 | 동시 통과 /8 | 전도 /10 |
|---|---|---:|---:|---:|---:|
| 1 | off | 5 | 4 | 2 | 0 |
| 1.1 | off | 8 | 4 | 4 | 0 |
| 1 | on | 3 | 7 | 2 | 0 |
| 1.1 | on | 8 | 6 | 6 | 0 |

속도 판정은 평가기의 원값 최소속도 ≥3.6 m/s와 별도 기록한 회전 구간 최대속도 ≤4.4 m/s를 모두 사용했다. 조합 후보의 남은 두 실패는 −1 rad/s에서 최소속도 3.2811/3.5533 m/s였다. 각도만 개선했다고 전체 통과로 보고하지 않는다. 모든 설정의 직진 2회 결과는 대조와 정확히 같았다. 40회 실행 exit 0. 입력 보정은 검증용 어댑터이며 운영 코드에 채택하지 않았다.

개발 초기상태 두 개와 한 학습 seed의 결과로 일반 성능을 확정할 수 없다. 전체 목표는 미완료이며, 131의 기립·정지 실패도 해결하지 못했다. 다음은 단일 보정 수치를 계속 늘리기보다 남은 왼쪽 빠른 회전의 접촉 순서·운동량 방향을 반대 회전과 비교한다. 논문에서의 접촉 계획과 전환 후 평가를 참고하되 다른 로봇의 성공을 랩터의 성공으로 대신하지 않는다.
