# 135 — 고정목표 기립의 초기 무릎 스프링 하중

같은8축 기구·기준자세·질량·토크한계·수동발가락·목표action=0에서 무릎스프링강성만 설계값170→0으로 비교했다. 초기상태22001/22002, 목표10초, 전도시종료. 실제 적용된 원강성은 기존 질량스케일에 의해168.9704N·m/rad다. 모터·기하·마찰·텐던정지각 배열과 reset qpos/qvel/ctrl의 정확일치를 별도 확인했다. 차이는 두 무릎 텐던강성뿐이다. source args만 임시 경로에서 복사해 진단했고 기존학습 모델/설정은 변경하지 않았다.

네 회 실제exit0이나 모두기립실패다. 원강성/22001의 모든행별원값은96의기준고정목표와정확히같다. 초기스프링은공통시간창의모터부하와자세에영향을주지만, 무력화해도두회모두전도하므로스프링해제만으로기립문제를해결하지못했다. 지표는각20ms동안(모터토크/가정연속토크)의제곱평균을처음10구간평균한것이다. 온도·실물발열·지속가능성을뜻하지않으며, 생존시간이서로다른전체평균으로개선을주장하지않는다.

초기 설정 계약의 첫검사는 강성이 스케일없이170이라고 가정해실패했다. 실제 배열검사에서168.9704임을 확인했고, 실제강성/초기상태와차이위치를기록해계약을수정했다. 코드오류를 물리실험실패로보고하지않는다.

강성0은원인을분리하는가상대조다. 실제걸쇠를정차중해제해도되는지·해제장치가제작가능한지·수동기립이가능한지는미검증이다. 운영모드나구조로채택하지않았다. 다음은정차중관절변형·몸통기울기·COM와지지영역을함께기록해,근본적인지지하중부족과피드백부재를분리한다. 회전의고속감속·기립·정지목표는여전히미완료이며goal active.
