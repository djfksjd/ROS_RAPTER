# 회전 평가의 명령·누적·원값 수정 — 2026-10-09

회전 명령을 바꾼 뒤 이전 관측으로 정책을 호출하던 한 제어 주기 지연과,
회전 시작의 첫 각도 증분을 누적하지 않던 결함을 수정했다.
마지막 평가 스텝에서 회전 구간이 끝나는 경우에도 완료된 회전량을 보존한다.
물리 환경·학습 정책은 변경하지 않았다. 평가 규약이 달라졌으므로 과거 결과를 덮어쓰지 않는다.

## 증거와 검사 범위

작은 결정적 제어 시험은 .04–.10초의 명령1 rad/s에 실제 실행 명령이
`[0,0,1,1,1,0,0]`이고 회전량은0.06 rad임을 확인한다.
구간 완료 전 전도는 실패, 마지막 스텝 완료는 보존한다.
양·음 방향 모두1.19996과1.20004를 같은 표시값1.20으로 반올림하더라도,
20% 경계 판정은 원값으로 각각 통과/실패해야 한다는 회귀 검사도 추가했다.

`--details-out`은 각 출발 seed·명령·회전 구간·전도·반올림 전 회전량을 JSONL에 즉시 기록한다.
정책·정규화 환경은 각 시험 뒤 닫는다. 기존 요약 JSON 형식은 유지한다.
`turn_pass_20pct`는 전도·미완료·비유한 원값을 통과시키지 않는다.
**이 플래그만으로 직진·발열·전체 동작 카탈로그가 통과한 것은 아니다.**

수정 평가기로 기존 기준선30회(직진2조건·회전4조건 × 출발5개)를 다시 실행했다.
전도0, 회전20회 중20% 추종 통과 **0/20**.
원 결과는 `scr_a8_h2.eval_v2.details.jsonl`, 조건별 원값은 `baseline-summary.json`.
평가 결함 수정만으로 기준선 회전 실패가 해결되지 않았다.

검사: `.venv-ai` 전체98개(41 환경 의존 생략), `.venv-sim` 관련25개 통과.
현재 두 명령 분포 학습이 완료되면 같은 규약으로 대조·집중 후보를 비교하고,
직진·60초 발열 검사를 별도로 시행한다. 통합 후보·회복·정지 전환은 미완료다.
