# 107 — 추가 loaded 관측의 학습 활용 진단

106의 48차원 최종 모델을 새 출발 seed52001에서 yaw−1/0/+1, 10초씩 재생했다. 실제 도달 관측에서 좌우 loaded 플래그만 반전한 가상 관측의 정책 출력을 추가 계산한다. 추가 출력은 물리 구동에 사용하지 않았다. 각 조건 계측off/on 한 쌍, 총6 rollout의 실제 action·qpos·qvel 정확일치 확인, 전도0. 같은 상태에서 플래그를 반전한 조합의 물리적 도달가능성은 증명하지 않았다.

초기0이었던 새 입력 열의 최대절댓값은 actor0.04947, critic0.03209이다. 회전구간 각100상태에서 두플래그 반전의 행동 최대차이는 −1:0.04105, 0:0.04967, +1:0.04525. 이는 정규화 행동의 차이며 rad·토크·회전량이 아니다. 추가 입력이 완전히 버려졌거나 초기0에서 전혀 학습되지 않았다는 설명은 관측과 맞지 않는다. 입력이 최적으로 활용됐다는 뜻도 아니다.

회전/기립/정지 목표의 실패 원인은 아직 확정되지 않았다. 관측 차원 확대만 반복하지 않고 다음에는 실제 명령별 보상 성분·loaded/phase 분포를 같은 정책으로 계측해 정지에서 보행을 지속하는 유인이 있는지 분리한다. 기준선·구동기·8행동·통과 기준 변경 없음. 진단 스크립트와 원값을 함께 보존했다.
