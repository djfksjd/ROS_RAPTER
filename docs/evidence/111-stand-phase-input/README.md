# 111 — 동결 정책의 기립 위상 입력 진단

110의 대조 최종 모델을 seed59001에서 영점명령으로 실행했다. 추론에 넣는 마지막sin/cos위상 입력만 None(원래)/0/0.25/0.5/0.75로 바꾼5조건이다. env.phase·보상·물리·관절 범위·46관측8행동은 유지한다. 매스텝 원래위상2값이 실제env.phase에 대응함을 확인하고 복사입력에서만 수정했다. source/최종model은 수정하지 않았다.

원래입력은60초전도없음이나이동1.156m/기울기0.190rad/flight60표본으로기립실패. 고정4조건은0.90/1.04/0.90/1.06초에각각전도(모두기립실패)했다. None과고정조건은다른정책입력으로다른행동을내므로궤적동등시험이아니다. 이결과는위상이학습된균형동작의일부임을보이고,기립때기존모델입력만멈추는방식은사용할수없음을확인한다. 주기적위상이현재기립실패의단일원인이라거나위상없는정책학습이불가능하다는뜻은아니다. OOD입력영향과학습분포의문제는분리되지않았다.

다음은추가보상가중치/관측한두개를같은방식으로재시도하기전에,실제학습정책의행동분포·클리핑비율과정차학습데이터비율을확인한다. 결정적평가는안정적으로움직이지만탐색분포가다르다면새기립/회전행동이발견되지않는경로를분리할수있다. 기존std0.25일괄변경(93)·회전축한정변경(101)의실패를보존하고같은실험을반복하지않는다. 전체회전/기립/정지목표미완료·후보미채택.
