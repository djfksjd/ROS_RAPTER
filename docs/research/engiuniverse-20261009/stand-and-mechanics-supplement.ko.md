# 기립·스프링·상태 추정 추가 조사

2026-10-09. 채널 121개 공개 목록, 전체 자동 자막 검토43개, 영상·음성 연속 완시청0개다. 이 문서는 원 논문/공식 코드의 추가 조사이며 영상 완시청 증거를 대체하지 않는다. 남은78개(일반36·Shorts42)의 본문 확인은 미완료다. 채널 페이지 추가 open은 cache miss, 과거 영상403/자막429로 접근하지 못했다. 비공개·삭제·유료 콘텐츠를 확인했다고 주장하지 않는다.

## 수동 발목과 상태 추정

Mercury/DRACO 연구는 수동 또는 준수동 발목으로도 전신제어·발 디딤 위치 계획을 활용할 수 있음을 보여준다. 접촉을 바꿀 때 반력 상한과 비용 가중치를 부드럽게 바꾼다. 실험의 전역 속도 추정은 MoCap과 encoder 융합에 의존했으므로 IMU만으로 같은 결과를 얻었다고 읽으면 안 된다. 랩터에는 초기 자세에서 양발 하중을 유지하며 평형으로 접근하는 경로와 관측 잡음/지연 시험을 별도로 마련하는 방향이 유용하다. 마지막 문장은 적용 제안이며 구현 완료 주장이 아니다. [원 논문 §3.1·6.3](https://arxiv.org/html/1901.08100).

## 스프링 강성과 실제 접촉

중국의 2010년 연구 초록은 경사 수동보행을 각 강성마다100회 실험했고 중간 강성에서 최대 안정성을 관측했다고 설명한다. 시뮬레이션에서는 강성과 흡인 영역이 함께 증가했지만 실제 발 끌림이 차이를 만들었다고 해석한다. 랩터에 같은 강성을 가져오는 대신 지면 이탈·발 끌림·접촉 지속·성공률을 함께 측정하는 실험 설계를 참고할 수 있다. 이는 고관절 스프링의 경사 수동보행이며 현재 랩터 무릎 걸쇠/평지 정차와 다르다. 초록만 확인했으며 전체 논문 검토가 아니다. [학술지 중영문 초록](https://pubs.cstam.org.cn/article/doi/10.6052/0459-1879-2010-3-2009-270?viewType=HTML).

## 정지에서 걷기로 출발

별도 중국 논문 초록은 직동 탄성 다리 B-SLIP에서 양발 지지 중 에너지 오차 PI, 유각 중 다리 회수를 결합한 출발 제어를 설명한다. 시뮬레이션 결과이며 실물 시험으로 표시하지 않는다. 랩터의 회전관절에 그대로 적용할 수 없지만 기립 유지와 출발을 별개 검증 단계로 나누는 참고다. 본문·매개변수·실행 코드까지 확보하지 못했다. [학술지 초록](https://www.joca.cn/CN/abstract/abstract25173.shtml).

## 공개 코드와 기어 설계

ATRIAS 저장소는 하드웨어·시뮬레이터·제어·후처리 폴더를 공개한다. README는 Windows MATLAB2014b+, Simulink Real-Time, SimMechanics를 요구한다. 현재 Mac MuJoCo 경로에 즉시 설치해 쓰는 라이브러리로 분류하지 않는다. 파일별 알고리즘·라이선스·재현은 추가 검토가 필요하다. [저장소 README](https://github.com/sir-avinash/atrias-matlab).

HOUND 공식 페이지는 기어비·기어 형상·모터 열 제약을 함께 고려한 전달계 최적화를 설명한다. 랩터도 실측 토크–속도 곡선과 열 특성, 실제 질량을 맞추는 설계 비교가 필요하다. 기존 랩터의 가상 연속 전류 상한 검증은 실물 모터 선정 완료가 아니다. [연구실 공식 페이지](https://www.dynamicrobot.kaist.ac.kr/kaist-hound-1).

## Reddit의 확인 수준

소형 모터의 토크·속도·열을 논의하는 글은 검색 스니펫만 확인했다. 직접 본문 접근은 실패했고 댓글 전체를 검증하지 못했다. 따라서 질문을 발굴하는 보조 자료로 남기며 제품 성능·실험 결론의 근거로 쓰지 않는다. [검색으로 발견한 토론](https://www.reddit.com/r/robotics/comments/s4fjsy/).
